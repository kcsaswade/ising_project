# Ising Model Simulation & Optimization

A CS + Physics project exploring:
- 2D Ising model using Metropolis Monte Carlo
- Interactive visualization with Pygame
- Performance optimization (Numba, multiprocessing, GPU)
- Applications to combinatorial optimization (TSP via annealing)

## Current Status
Stage 1: Core simulation (in progress)
Stage 2: GUI (planned)

python main.py
